# سجل المتابعة — نظام الإشراف والملاحظات المدرسية

نظام إشرافي مجاني يعمل بالكامل داخل المتصفح على الهاتف والكمبيوتر، بدون خادم. مُعدّ لـ **المدرسة القرآنية الوقفية · ولاية العامرات**.

## المزايا

- **متعدد المشرفين** — لكل مشرف اسم مستخدم وكلمة سر وحافظة بيانات منفصلة تماماً.
- **أفرع وملاحظات** — عدد غير محدود من الأفرع، ولكل فرع سجل زيارات مستقل، وأيقونة لونية مميّزة.
- **حقول الملاحظة** — تاريخ الزيارة، نوعها، التقييم العام، المدرسة والبيئة، حالة المرافق، المعلمات، مدير المدرسة، الأداء الصفي، نقاط القوة، جوانب التطوير، والتوصيات.
- **قوائم بدل الكتابة** — خيارات جاهزة كأزرار يمكن تعديلها بالكامل من الإعدادات.
- **لوحة متابعة تفاعلية** — مؤشر أداء عام، توزيع التقييمات، ترتيب الأفرع، وأبرز جوانب التطوير.
- **رسم بياني** — تطوّر التقييم العام لكل فرع عبر الزيارات.
- **تصدير PDF** — تقرير رسمي بترويسة الشعار (يحتاج اتصالاً بالإنترنت أول مرة).
- **حفظ محلي** — البيانات تُخزَّن على الجهاز فقط (localStorage).
- **تصدير/استيراد** — نقل النسخة بين الأجهزة عبر ملف واحد.

## استرجاع الدخول عند نسيان كلمة السر

في شاشة الدخول، اضغط «استرجاع الدخول»، ثم أدخل رمز مدير النظام: **OMAN-2025**، وبعدها يمكن تعيين كلمة سر جديدة.
> يُنصح بتغيير هذا الرمز من الكود (ثابت `MASTER_CODE` في `index.html`) قبل التوزيع.

## النشر على GitHub Pages

1. أنشئ مستودعاً جديداً على GitHub وارفع كل ملفات هذا المجلد إليه.
2. من `Settings` ← `Pages`، اختر الفرع `main` والمجلد `/ (root)`.
3. احفظ، وبعد دقائق سيظهر رابط التطبيق مثل: `https://USERNAME.github.io/REPO/`.
4. افتح الرابط على الهاتف وأضِفه للشاشة الرئيسية ليعمل كتطبيق.

## التشغيل محلياً

افتح `index.html` مباشرة بأي متصفح — لا يحتاج تثبيت أو خادم.

## الخصوصية

جميع البيانات محفوظة محلياً على جهاز كل مشرف. لا يتم إرسال أي بيانات لأي خادم.
